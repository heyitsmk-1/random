# Livestream: Rules

The rules for working on this project. This list grows as we work.
Each rule keeps its number forever; if a rule is changed or dropped, it is marked here instead of deleted.

---

## Rule 1: No code until "CLAUDE COOK"

Never write, edit, or generate any code until the project owner says, verbatim:

> **CLAUDE COOK**

- It must be that exact phrase. "Go ahead", "start coding", "looks good", and similar do not count.
- Until then, only planning, discussion, and documentation (like these files) are allowed.
